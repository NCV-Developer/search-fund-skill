一个面向中国语境的中英双语搜索基金（Search Fund / ETA）科普技能，供 AI agent 加载使用。

A bilingual (Chinese/English) primer on search funds and entrepreneurship through acquisition, packaged as an agent skill.

语言：默认英文回答；对方用中文提问或要求中文时，整段切换中文。两边数据与免责声明完全一致。

## 这是什么

搜索基金是：一个人或两个人，先向一小群认同其能力的投资人募集一笔搜寻资金，用一到三年找到并收购一家私营企业，然后自己担任 CEO，持有六到十年。

与 PE 的根本区别是顺序——先有人，后有标的。

这个技能回答四类问题：

  搜索基金是什么、回报与风险的真实分布
  中国能不能做、为什么难，以及中国与欧美的生态差距
  它为什么被视为一个资产类别，判断标准是什么
  企业主、想买公司的人、投资人、专业服务商分别该怎么看这件事
